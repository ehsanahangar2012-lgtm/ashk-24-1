# راهنمای کامل راه اندازی و انتشار سامانه اشک ۲۴ روی هاست اشتراکی سی‌پنل (بدون نیاز به Node.js)

این راهنما قدم به قدم روش راه اندازی سامانه هوشمند اتوماسیون بازاریابی **اشک ۲۴** را روی تمامی هاست‌های سی‌پنل (cPanel) بدون نیاز به نصب Node.js یا دسترسی SSH توضیح می‌دهد.

---

## 🏗️ ساختار سیستم در هاست سی‌پنل

در این معماری:
1. **بخش فرانت‌اند (رابط کاربر):** فایل‌های کامپایل‌شده استاتیک ری‌اکت (موجود در پوشه `dist`) هستند که مستقیماً توسط وب‌سرور آپاچی/لایت‌استپ سرو می‌شوند.
2. **بخش بک‌اند (سرویس‌ها و API):** کدهای PHP کاملاً مستقل (بدون نیاز به Node.js) در پوشه `api` اجرا شده و تمام سرویس‌ها (تولید محتوا، سئو، آنالیز DOM، مدیریت کمپین‌ها و وب‌هوک‌ها) را پردازش می‌کنند.

---

## 🚀 مراحل انتشار روی سی‌پنل (Step-by-Step Deployment)

### مرحله ۱: خروجی گرفتن از فرانت‌اند (Build)
در سیستم شخصی خود دستور زیر را اجرا کنید:
```bash
npm run build
```
پس از اجرای این دستور، یک پوشه به نام `dist` ایجاد می‌شود که حاوی فایل‌های `index.html` و پوشه `assets` است.

---

### مرحله ۲: آپلود فایل‌های فرانت‌اند در سی‌پنل
1. وارد کنترل‌پنل **cPanel** هاست خود شوید.
2. وارد **File Manager** شده و به پوشه `public_html` بروید.
3. تمامی محتویات داخل پوشه `dist` (شامل `index.html` و پوشه `assets`) را به داخل `public_html` آپلود کنید.

---

### مرحله ۳: آپلود کدهای بک‌اند PHP
1. فایل‌های زیر را از پوشه `cpanel-backend` پروژه به داخل همان `public_html` منتقل نمایید:
   - `config.php`
   - `db.php`
   - `ai_engine.php`
   - `.htaccess`
   - `test_api.php`
   - پوشه `api` (حاوی `index.php`)
   - پوشه `data` (حاوی `db.json`)

پوشه `public_html` شما باید ساختاری شبیه به زیر داشته باشد:
```text
public_html/
├── assets/                  # فایل‌های JS و CSS تولید شده ری‌اکت
├── api/                     # مسیریاب اصلی APIهای PHP
│   └── index.php
├── data/                    # پوشه ذخیره‌سازی داده‌های برنامه
│   └── db.json
├── .htaccess                # تنظیمات مسیریابی آپاچی و CORS
├── ai_engine.php            # موتور دوگانه هوش مصنوعی
├── config.php               # تنظیمات اصلی بک‌اند
├── db.php                   # مدیریت دیتابیس فایل‌محور PHP
├── index.html               # صفحه اصلی فرانت‌اند
└── test_api.php             # اسکریپت تست سلامت هاست
```

---

### مرحله ۴: تنظیم مجوز دسترسی پوشه data (Permissions)
برای اینکه PHP بتواند اطلاعات کمپین‌ها، کاربران و آگهی‌ها را ذخیره کند:
1. در File Manager سی‌پنل روی پوشه `data` راست کلیک کرده و گزینه **Change Permissions** را بزنید.
2. مجوز آن را روی **`775`** یا **`777`** قرار دهید.

---

### مرحله ۵: موتور هوش مصنوعی و پردازش آفلاین
سامانه اشک ۲۴ به **موتور آفلاین محلی فارسی (Local Heuristic Engine)** و هوش درون‌برنامه‌ای مجهز است و تمامی آگهی‌ها و آنالیزهای سئو را بدون نیاز به هیچ کلید خارجی یا اتصال اینترنت بین‌الملل و بدون قطعی در سرور cPanel پردازش و تولید می‌کند.

---

### مرحله ۶: تست سلامت و اجرای نهایی
آدرس زیر را در مرورگر خود باز کنید:
```text
http://your-domain.com/test_api.php
```
در صورت مشاهده پیغام‌های سبز رنگ **«فعال ✓»**، سیستم شما ۱۰۰٪ آماده کار است و می‌توانید با ورود به آدرس اصلی دامنه خود (`http://your-domain.com`) از سامانه اشک ۲۴ لذت ببرید!

## 🛠️ عیب‌یابی (Troubleshooting)

| مشکل | علت احتمالی | راه حل |
| :--- | :--- | :--- |
| **خطای 404 در درخواست‌های API** | فعال نبودن mod_rewrite در آپاچی یا نبود فایل `.htaccess` | فایل `.htaccess` را حتماً در `public_html` قرار دهید و از فعال بودن RewriteEngine مطمئن شوید. |
| **خطای 500 هنگام ذخیره‌سازی** | عدم مجوز دسترسی نوشتن به پوشه `data` | مجوز (Permission) پوشه `data` را به `775` یا `777` تغییر دهید. |
| **عدم نمایش آگهی جدید** | کش مرورگر یا عدم پاسخگویی cURL | فایل `test_api.php` را اجرا کرده و از فعال بودن cURL مطمئن شوید. |
