| روش استقرار | نیاز به Node.js | ذخیره‌سازی داده‌ها | مناسب برای |
| :--- | :---: | :---: | :--- |

## 🛠️ روش اول: حالت هاست معمولی (Pure Static Mode) — بدون نیاز به هیچ سروری

در این حالت نیازی به نصب Node.js یا هیچ پیش‌نیاز سروری روی هاست ندارید:

1. **ساخت فایل‌های نهایی (Build):**
   در کامپیوتر خود یا در محیط کنسول دستور زیر را اجرا کنید:
   ```bash
   npm run build
   ```
2. **آپلود فایل‌ها:**
   وارد مدیریت فایل (File Manager) در cPanel شوید و محتویات پوشه `dist` (شامل فایل `.htaccess` و پوشه `assets` و `index.html`) را مستقیماً داخل پوشه `public_html` آپلود و خارج از زیپ (Extract) کنید.
3. **تنظیم حالت اجرایی سامانه:**
   پس از باز کردن سایت، از بالای سامانه (نوار Navbar) دکمه سوئیچ را روی **«حالت هاست معمولی (بدون Node.js)»** قرار دهید.
   - تمام اطلاعات در ذخیره‌ساز مرورگر ثبت می‌شود.
   - عکس‌ها به صورت اتوماتیک به Base64 تبدیل می‌شوند.
   - هیچ خطای 404 یا عدم پاسخ سرور رخ نخواهد داد.
4. **پشتیبان‌گیری از داده‌ها:**
   در تب «کاوش رسانه»، می‌توانید در هر زمان با زدن دکمه **«خروجی دیتابیس (JSON)»** یک نسخه پشتیبان از تمام اطلاعات خود دانلود کرده و در دستگاه‌های دیگر بارگذاری (Import) کنید.

## 🐍 روش دوم: استفاده از اسکریپت پایتون (`backend.py`) به عنوان بک‌اند جایگزین

اگر هاست cPanel شما امکان اجرای Node.js ندارد اما دارای پایتون (Python Selector) است:

1. **آپلود فایل `backend.py`:**
   فایل `backend.py` موجود در پروژه را در ریشه هاست (`public_html`) آپلود کنید.
2. **فعال‌سازی در cPanel:**
   - وارد بخش **Setup Python App** در cPanel شوید.
   - یک برنامه جدید ایجاد کرده و مسیر فایل استارت‌آپ را `backend.py` قرار دهید.
3. **تنظیم فایل `.htaccess`:**
   کافیست خط زیر را در فایل `.htaccess` از حالت کامنت خارج کنید تا درخواست‌های `/api` به پایتون منتقل شوند:
   ```apache
   RewriteRule ^api/(.*)$ backend.py [QSA,L]
   ```

## 🟩 روش سوم: استقرار سرور Node.js در cPanel (`app.js`)

اگر هاست شما دارای ابزار **Setup Node.js App** است:

1. **تنظیم برنامه در cPanel:**
   - Node.js Version: نسخه 18 یا بالاتر.
   - Application Startup File: `app.js`
2. **اجرای Build:**
   دستور `npm run build` را اجرا کنید تا `dist/server.cjs` ساخته شود.
3. **راه اندازی:**
   دکمه **Restart Application** را در cPanel بزنید.

## 📄 فایل پیکربندی `.htaccess` جهت جلوگیری از خطای 404

فایل `.htaccess` آماده در پروژه به صورت زیر تنظیم شده است:

```apache
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  Options -Indexes

  # هدایت روت‌های ریکت جهت جلوگیری از خطای 404
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule ^ index.html [L]
</IfModule>

<IfModule mod_mime.c>
  AddType application/javascript .js .mjs
  AddType text/css .css
  AddType image/svg+xml .svg
  AddType application/json .json
</IfModule>
```
